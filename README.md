# Reconstructing Missing Indoor CO₂ Measurements from Smart-Building Sensors

MMA3001 Numerical Methods and Machine Learning — Individual Project (Dataset 2:
Monash Smart Infrastructure Occupancy and Environmental Data).

> **Status:** work in progress. Sections marked *TODO* are completed as the project
> develops. See the commit history for progress.

## 1. Purpose

Building ventilation control and indoor-air-quality reporting rely on continuous CO₂
records, but wireless environmental sensors drop readings. This project develops and
validates a method for **reconstructing missing CO₂ readings** and identifies which
method to use for which gap length.

* **Input:** time-stamped indoor CO₂ readings (ppm, about 10-minute sampling) from the
  Monash environmental-sensor extract, plus the positions of missing samples.
* **Output:** reconstructed CO₂ values (ppm) for each missing sample, a flag for
  unsupported gaps, and validation metrics (RMSE, MAE, overshoot in ppm) for each method
  and gap length.
* **Intended use:** gap-filling before computing daily indoor-air-quality summaries.
  It is not a substitute for real measurements in compliance or safety decisions.

## 2. Methods (summary)

| Role | Method | Unit content |
| --- | --- | --- |
| Data audit | Duplicate removal, coverage, validity and rate-of-change rules | Weeks 5.6, 7.1 |
| Main candidates | Linear, PCHIP, Akima and cubic-spline interpolation | Weeks 3.1, 3.4 |
| Long-gap alternative | Regression on time-of-day / weekday features | Week 5 |
| Physics alternative (tested) | Calibrated single-zone CO₂ ODE, Euler/RK4 | Weeks 7.2–7.4 |
| Evaluation | Masked-gap validation against known values; time-ordered split | Weeks 5.5, 5.6 |
| Performance | `%timeit`, line_profiler, Scalene, FLOP / arithmetic-intensity estimates | Week 2.1 |

## 4. Data

The raw file `5EnvSensor_MayToDec2024_180kRows.csv` (≈353 MB, 179,447 rows) is supplied
by the MMA3001 teaching team and is **not committed** to this repository because of its
size. To reproduce the full analysis:

1. Download the file from the Dataset 2 link on the unit's Moodle page.
2. Place it at `data/raw/5EnvSensor_MayToDec2024_180kRows.csv`.

The cleaned CO₂ series produced by `notebooks/01_data_audit.ipynb` are committed as
`data/sample/co2_clean.csv` (two sensors, 42,838 readings), so later notebooks run
without the raw file.

## 5. Installation

Requires Python 3.10 or newer.

~~~bash
git clone <repository-url>
cd co2-gap-reconstruction
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
pip install -e .                 # makes `import co2gaps` work everywhere
~~~

## 6. Usage

Run the notebooks in `notebooks/` in numbered order (see `notebooks/README.md`). In Google
Colab, each notebook's first cell clones this repository, installs the package and links
the raw data from Google Drive.

Quick start with the package:

~~~python
from co2gaps import io

raw = io.load_raw("data/raw/5EnvSensor_MayToDec2024_180kRows.csv")
clean, report = io.deduplicate(io.parse_jsondata(raw))   # CO2 readings, repeats removed
co2 = io.co2_series(clean, "6012002000869")              # time-indexed series (ppm)
io.audit_series(co2)                                      # coverage, gaps, validity
~~~
